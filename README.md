# EISOP Annotation File Utilities

**This repository has moved.**
The Annotation File Utilities are now developed in the
[`annotation-file-utilities`](https://github.com/eisop/checker-framework/tree/master/annotation-file-utilities)
directory of the [EISOP Checker Framework](https://github.com/eisop/checker-framework)
repository, and are released together with it.
Please file issues and pull requests there.
This repository is no longer maintained and will be archived.

- Releases: `annotation-file-utilities-VERSION.zip` is attached to the
  [GitHub releases of the EISOP Checker Framework](https://github.com/eisop/checker-framework/releases),
  and the Maven artifact is
  [`io.github.eisop:annotation-file-utilities`](https://central.sonatype.com/artifact/io.github.eisop/annotation-file-utilities).
  The last release from this repository is 3.49.5-eisop1.
- Documentation: see the
  [Annotation File Utilities homepage](https://eisop.github.io/afu/).
